# ArvoCulture

Shopify'dan bağımsız, Vercel üzerinde çalışacak Next.js e-ticaret vitrini.

## Başlangıç

```bash
npm install
npm run dev
```

## Yol haritası

- Kalıcı ürün, stok, müşteri ve sipariş veritabanı
- Yönetim paneli
- PayTR iFrame API / Direct API entegrasyonu ve callback doğrulaması
- Kargo ve e-fatura entegrasyonları

PayTR anahtarları hiçbir zaman istemci tarafına aktarılmamalı; `.env.example` yalnızca gerekli değişken isimlerini gösterir.
